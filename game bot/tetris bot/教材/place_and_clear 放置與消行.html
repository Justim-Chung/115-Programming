FROM A MOVE TO A NEW BOARD

place_and_clear()：放置方塊與消行

目的：算出放置方塊並消行後，盤面會變成什麼樣子，並回傳新盤面和消掉的列數。

複製　→　放置　→　檢查　→　消行
0°點左邊盤面或欄號，選擇放置欄位。
比較兩份盤面BEFORE & AFTER

紫色虛線表示預測落點。右邊的變化不會改動左邊的原盤面。

原盤面 board 點選任一格或欄號選欄位
試算盤面 new_board 觀察放置、檢查與消行
原有方塊預測落點新放方塊：0 → 1已檢查、填滿的列
一步步試算STEP BY STEP
對照 Python 程式PLACE_AND_CLEAR
def place_and_clear(board, shape, row, col): new_board = [line[:] for line in board] for r in range(len(shape)): for c in range(len(shape[0])): if shape[r][c]: new_board[row + r][col + c] = 1 remaining = [line for line in new_board if 0 in line] cleared = ROWS - len(remaining) return [[0] * COLS for _ in range(cleared)] + remaining, cleared
記住試算時修改的是 new_board 的副本；原本的 board 不變，才能公平比較下一種放法。
