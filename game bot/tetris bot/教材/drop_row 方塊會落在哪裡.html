對照 Python 程式DROP_ROW FUNCTION
def drop_row(board, shape, col): if not fits(board, shape, 0, col): return None row = 0 while fits(board, shape, row + 1, col): row += 1 return row
每次呼叫 fits() 都是在問：方塊放在指定位置，會出界或碰撞嗎？
記住drop_row() 是在程式裡「試放」，不會移動遊戲畫面。藍色虛線是算出的最終落點；藍色橫列標示方塊左上角所在的列，黃色／紅色顯示起點或目前試放的位置。
