FROM BOARD TO HOLE COUNT

count_holes()：盤面有多少個洞？

讓電腦逐欄往下看，算出有多少空格被上方的方塊蓋住。

逐欄掃描　→　記住方塊　→　累計空格
模擬盤面BOARD · 20 × 10

範例是先放下橫向 I，再放下旋轉 180° 的 L。點任一格可增加或移除方塊；修改後會重新計數。

方塊（1）已發現的洞（0）正在檢查
定義

在同一欄中，某個空格的上方有至少一個方塊，就算一個洞。上方沒有方塊的空格，不算洞。

從上往下掃描STEP BY STEP
對照 Python 程式COUNT_HOLES
def count_holes(board): holes = 0 for col in range(COLS): covered = False for row in range(ROWS): if board[row][col]: covered = True elif covered: holes += 1 return holes
換到新的一欄時，covered 會重新設為 False；洞的總數則繼續累計。
記住這裡的「洞」依照程式的同欄上方是否有方塊來定義，並沒有另外搜尋空格能否從側面抵達。count_holes() 回傳的是洞的數量，不會修改盤面。
