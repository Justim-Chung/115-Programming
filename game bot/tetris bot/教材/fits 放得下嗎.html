FROM POSITION TO DECISION

fits()：這個位置放得下嗎？

點選盤面的一格，讓電腦逐格檢查方塊是否出界或碰撞。

位置　→　逐格檢查　→　True / False
模擬盤面BOARD · 20 × 10

點選盤面一格，作為 shape 左上角。右側和底部留白用來顯示出界。

已落地方塊放置預覽正在檢查
先決定要放什麼SHAPE & POSITION
0°改變位置或形狀後，檢查會重新開始。
範例
逐格檢查STEP BY STEP
shape：每一個數字對應一格
對照 Python 程式FITS FUNCTION
def fits(board, shape, row, col): for r in range(len(shape)): for c in range(len(shape[0])): if shape[r][c]: y, x = row + r, col + c if (y < 0 or y >= ROWS or x < 0 or x >= COLS or board[y][x]): return False return True
為了容易閱讀，這裡將原程式的一行判斷拆成多行；執行邏輯相同。
記住fits() 只回答「這個位置放得下嗎？」不會移動方塊。讓方塊往下試，是 drop_row() 的工作。
