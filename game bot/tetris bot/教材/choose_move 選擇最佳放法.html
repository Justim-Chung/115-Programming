choose_move()：如何選擇最佳放法？

逐一試放、計算分數，再從所有可放的方向與欄位中選出最高分。

對照 Python 程式CHOOSE_MOVE
def choose_move(board, piece): best = None for turns, shape in enumerate(rotations(SHAPES[piece])): for col in range(COLS - len(shape[0]) + 1): row = drop_row(board, shape, col) if row is None: continue after, cleared = place_and_clear(board, shape, row, col) score = row + 100 * cleared - 50 * count_holes(after) if best is None or score > best[0]: best = (score, turns, col, row, after) return best
記住：這是試算放法，並不會操作遊戲。洞的扣分依據的是放置並消行後的全部洞數；若最高分相同，程式保留先遇到的放法。
